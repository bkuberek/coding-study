# Probe

A project for the runner conformance suite: `src/main/java/probe/Probe.java` defines the entry class `probe.Probe`, and the reference adds `src/test/java/probe/StatusesTest.java`, whose tests cover every status of a suite job, and `BrokenSetupTest.java`, whose setup fails.

`cstudy` loads `probe.Probe`. Run the tests with `../../jvm/gradlew test`.
