# Code of conduct

coding-study is for everyone who wants to learn, from beginners to experts. This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct, for issues, pull requests, discussions and every other project space.

In short:

- be kind and patient, especially with people who are just starting out;
- critique ideas and code, never people;
- no harassment, insults or personal attacks;
- respect other people's privacy.

## Reporting

To report behaviour that breaks this code, use GitHub's **Report content** option on the comment, issue or pull request, or report the account to GitHub. Reports are handled in confidence, and the maintainer may remove content or block anyone who breaks this code, following the Contributor Covenant's enforcement guidelines.
